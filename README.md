# English Coach

Бесплатный офлайн-тренажёр языка для macOS. Живёт в menu bar, не требует браузера, регистрации, подписки, API-ключа или подключения к интернету.

## Два языка

Приложение учит **английскому** и **испанскому**. Язык выбирается на первом экране и меняется
из шапки маршрута или настроек. Разделены не только уроки: у каждого языка свой тест на уровень,
своя программа грамматики, свой прогресс со стриком и повторениями, свой голос озвучки и свой
акцентный цвет (английский — индиго, испанский — терракота). Занятия по одному языку не влияют
на другой, и переключение ничего не сбрасывает.

Оба курса собраны на всех уровнях, A1–C1: уроки, карточки, переводы, сборка предложений и тесты,
плюс свой тест на уровень. В испанском 409 упражнений, в английском 422.

## Что уже есть

- выбор языка: английский или испанский, с раздельным прогрессом;
- уровни A1, A2, B1, B2 и C1;
- тест на уровень при первом запуске (заканчивается, как только уровень ясен) и повторный тест из настроек;
- яркая карта курса и свободный каталог;
- дневная цель в минутах и подсказка перейти на уровень выше, когда текущий пройден;
- короткие правила, карточки, перевод с русского, сборка предложений и тесты;
- повторение вслух за системным диктором: фраза озвучивается, ты повторяешь, приложение
  записывает тебя и даёт послушать свою попытку сразу за эталоном;
- режим «на слух»: предложение только звучит, текста на экране нет — ты записываешь, что
  услышал, и приложение показывает, какие слова не долетели;
- мгновенная проверка по подготовленным вариантам ответа, по правилам своего языка: в английском
  сходятся сокращения и британское написание, в испанском пропущенное ударение засчитывается как
  описка, а перепутанное окончание — нет, потому что оно и есть грамматика;
- локальные очки, стрик, ошибки и интервальные повторения;
- системная озвучка на языке курса и ежедневные напоминания;
- все данные остаются на Mac пользователя.

Это законченный учебный цикл на реальном объёме материала, а не многолетний курс: у обоих языков собраны все пять уровней, но одна глава на тему, а не десять.

## Установка из DMG

1. Открой `English-Coach.dmg` из раздела Releases.
2. Перетащи **English Coach** в **Applications**.
3. Запусти приложение. Откроется окно с маршрутом, а значок останется в menu bar — через него можно вернуться к уроку или повторению в любой момент.

Текущая сборка подписывается локальной ad-hoc подписью и не нотариализована Apple. При первом запуске macOS может попросить открыть приложение через **System Settings → Privacy & Security → Open Anyway**. Для бесшовной установки нужна платная учётная запись Apple Developer и нотариальное заверение.

## Сборка из исходников

Требования: macOS 14 или новее и актуальные Apple Command Line Tools.

```bash
cd native
swift run EnglishCoachCoreTests
cd ..
chmod +x scripts/build-macos-app.sh scripts/create-dmg.sh
scripts/create-dmg.sh
```

Готовые файлы появятся в `dist/`.

## Версия для телефона (PWA)

**Открыть: https://x8bvgp4hv8-beep.github.io/english-coach/**

В `web/` лежит веб-клиент на том же контенте: он ставится на iPhone и Android из браузера,
без App Store, без аккаунта разработчика и без установки чего-либо ещё.
Каждый коммит в `web/` пересобирает и публикует его заново (`.github/workflows/deploy-web.yml`),
причём деплой не проходит, пока не прошли тесты ядра.

```bash
cd web
npm install
npm run build     # dist/ — статические файлы, готовые к раздаче
npm test          # 45 тестов ядра, те же проверки, что и в Swift
npm run dev       # локальная разработка на http://localhost:5173
```

Курсы не дублируются: `npm run sync-content` копирует их из `native/Sources/EnglishCoachCore/Resources/Languages/`
перед каждой сборкой, так что источник контента один. В вебе язык становится папкой
(`content/es/courses/a1.json`), а префикс из имени файла снимается.

### Как выложить

Подойдёт любой статический хостинг **по HTTPS** (Cloudflare Pages, GitHub Pages, Netlify, Vercel):
залей содержимое `web/dist/`. HTTPS обязателен — без него браузер не включит офлайн-режим.

### Как поставить на iPhone

1. Открой ссылку **в Safari**. Через Chrome на iOS установка не работает — это самая частая причина «у меня не ставится».
2. Кнопка «Поделиться» → **«На экран „Домой“»**.
3. Запускать с иконки на рабочем столе: приложение открывается на весь экран, без адресной строки, и работает без интернета.

На Android то же самое делает Chrome: меню → «Установить приложение».

### Обновления

Приложение обновляется само. При каждом возвращении на передний план оно спрашивает сервер,
не вышла ли новая сборка, и переключается на неё, как только экран свободен, — то есть обычно
на следующем запуске. Посреди упражнения версия не меняется: сверху появляется полоска
«Готова новая версия», и обновление применяется, когда урок закончен (или сразу, если нажать
на полоску). В настройках видны «Версия сборки» и «Проверить обновление».

Так было не всегда: `registerType: 'autoUpdate'` в vite-plugin-pwa только выставляет service
worker'у `skipWaiting`, а страницу не перезагружает, и вся проверка обновления висела на событии
`load`, которого у приложения с экрана «Домой» на iOS почти не бывает — оно восстанавливается
из снапшота. Из-за этого установленная копия могла жить на сборке двухнедельной давности, ничего
об этом не сообщая. Лечение — в `web/src/app/sw-update.ts`.

### Прогресс

Хранится только на самом телефоне, у каждого языка отдельно. Safari может очистить данные сайтов,
которыми долго не пользовались, поэтому в настройках есть «Сохранить копию прогресса» файлом и
восстановление из него; копия относится к текущему языку.

## Напоминания

На Маке напоминание локальное: система показывает его сама, интернет и сервер не нужны.
В настройках рядом с тумблером стоит строка «Запланировано» — она показывает не сохранённый
флаг, а то, что реально стоит в очереди у macOS, потому что раньше эти две вещи расходились:
пересборка приложения стирала запланированное уведомление, тумблер продолжал показывать
«включено», и напоминания просто переставали приходить. Теперь оно перевзводится при каждом
запуске и при смене языка (его текст называет язык), а отказ в разрешении выключает тумблер
и говорит причину вместо того, чтобы промолчать.

На телефоне напоминаний пока нет: они требуют веб-пуша, а значит своего сервера. Клиентская
часть написана (`web/src/app/push.ts`, `web/public/push-sw.js`), но воркер из `server/README.md`
не развёрнут и `PUSH_ENDPOINT` в `web/src/app/push-config.ts` пустой — поэтому в настройках
честно написано «сервер не подключён». Плюс ограничение платформы: на iPhone веб-пуш работает
с iOS 16.4 и только у приложения, добавленного на экран «Домой».

## Приватность

Публичная версия не делает сетевых запросов. Профиль и прогресс хранятся в `~/Library/Application Support/EnglishCoach/state.json` (английский)
и `state-<код>.json` для остальных языков. Удаление файла сбрасывает прогресс этого языка.

Запись голоса никуда не отправляется и не распознаётся: она живёт во временном файле ровно до
следующей фразы, а потом удаляется. Микрофон запрашивается только при первом нажатии на кнопку
записи; без разрешения повторение вслух всё равно работает — сравнивать придётся на слух.

## Учебные материалы

Оригинальные курсы лежат в `native/Sources/EnglishCoachCore/Resources/Languages/<код>/`: по одному
файлу на уровень плюс `<код>-placement.json` (тест на уровень) и `<код>-syllabus.json` (программа
грамматики уровня). Префикс в имени обязателен: SwiftPM складывает ресурсы в корень бандла плоско,
и два `a1.json` там бы столкнулись. Формат JSON версионирован и не зависит от SwiftUI, поэтому те
же пакеты можно использовать в приложениях для iPhone и Android.

Третий язык — это строка в `Language.swift` / `language.ts` и папка с контентом. Всё остальное
(загрузка, прогресс, озвучка, палитра, тесты) уже написано «на язык», а не на английский: набор
тестов `each shipped language` прогоняет новый язык теми же проверками, что и первые два, и не
пропустит пакет с пустой темой, неверным вариантом ответа или несобираемой фразой.

`syllabus.json` держит долг покрытия: `coverageDebtCeiling` — это число тем, для которых упражнений
пока меньше нормы. Тест не даёт ему вырасти. У обоих языков долг 0: каждая тема программы
подкреплена упражнениями, и потолок обратно уже не поднимется.

Проект вдохновлён идеей коротких уроков, активного воспроизведения и интервального повторения. Тексты, упражнения, дизайн и материалы Dad English не копируются.
