# English Coach

Бесплатный офлайн-тренажёр английского для macOS. Живёт в menu bar, не требует браузера, регистрации, подписки, API-ключа или подключения к интернету.

## Что уже есть

- уровни A1, A2, B1, B2 и C1;
- яркая карта курса и свободный каталог;
- короткие правила, карточки, перевод RU → EN, сборка предложений и тесты;
- мгновенная проверка по подготовленным вариантам ответа;
- локальные очки, стрик, ошибки и интервальные повторения;
- системная английская озвучка и ежедневные напоминания;
- все данные остаются на Mac пользователя.

MVP содержит по одной законченной стартовой главе для каждого уровня. Это демонстрация полного учебного цикла, а не полный многолетний курс.

## Установка из DMG

1. Открой `English-Coach.dmg` из раздела Releases.
2. Перетащи **English Coach** в **Applications**.
3. Запусти приложение. Значок появится в menu bar.

Текущая сборка подписывается локальной ad-hoc подписью и не нотариализована Apple. При первом запуске macOS может попросить открыть приложение через **System Settings → Privacy & Security → Open Anyway**. Для бесшовной установки нужна платная учётная запись Apple Developer и нотариальное заверение.

## Сборка из исходников

Требования: macOS 14 или новее и актуальные Apple Command Line Tools.

```bash
cd native
swift run EnglishCoachCoreTests
cd ..
chmod +x scripts/build-macos-app.sh scripts/create-dmg.sh
scripts/create-dmg.sh
```

Готовые файлы появятся в `dist/`.

## Приватность

Публичная версия не делает сетевых запросов. Профиль и прогресс хранятся в `~/Library/Application Support/EnglishCoach/state.json`. Удаление этого файла сбрасывает прогресс.

## Учебные материалы

Оригинальные курсы лежат в `native/Sources/EnglishCoachCore/Resources/Courses/`. Формат JSON версионирован и не зависит от SwiftUI, поэтому в будущем те же пакеты можно использовать в приложениях для iPhone и Android.

Проект вдохновлён идеей коротких уроков, активного воспроизведения и интервального повторения. Тексты, упражнения, дизайн и материалы Dad English не копируются.

## Личная AI-версия

Старый Python-прототип с голосовым AI-разговором остаётся личным локальным инструментом и не входит в публичную сборку или Git-историю.
