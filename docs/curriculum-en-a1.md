# Английский A1 — программа на 90 часов

Тридцать блоков по семнадцать уроков: шестнадцать обычных по 11 минут и проверка на 5.
Блок ≈ 3 часа, курс ≈ 90 часов — нижняя граница нормы Cambridge для A1 (см.
[hours.md](hours.md)).

Последовательность повторяет испанский A1, который уже закрыт по норме и проверен на
живом человеке: темы бытовые и идут в том порядке, в каком они нужны, а грамматика
подкладывается под тему, а не наоборот. Грамматический инвентарь — двенадцать тем A1 из
`en-syllabus.json` (English Grammar Profile), тематических тем шестнадцать.

## Устройство урока

Одно и то же в каждом уроке — лестница из `ContentRepository` (шаг не идёт вниз):

1. **dialogue** — пять реплик: язык целиком, до всякого разбора;
2. **пять flashcard** — слова и выражения из этого диалога;
3. **info** — правило, объясняющее то, что уже прозвучало;
4. **три multiple_choice** — узнавание, ответ перед глазами;
5. **word_order** — сборка фразы из слов;
6. **три translate** — производство с нуля.

Проверка блока: шесть переводов, без подсказок, только производство.

## Долг покрытия

Шестнадцать тематических тем добавлены в `en-syllabus.json` сразу, а содержание под них
пишется блоками. Пока блоков нет, эти темы — долг, и он записан честно:
`coverageDebtCeiling` равен числу непокрытых тем. Потолок опускается с каждой волной и
обязан дойти до нуля — это ратчет, а не разрешение забить.

Курс публикуется в `native/.../en-a1.json` не раньше, чем новые блоки покроют всё, что
покрывает нынешний черновик на 1.7 часа: иначе обновление на телефоне уменьшит курс.
До этого волны коммитятся как исходники в `content-src/` — они ни на что не влияют,
пока их не собрали.

## Как собирается

Автор пишет только язык — в `content-src/en/a1/NN-slug.mjs`. Идентификаторы, порядок,
минуты и теги раскладывает `tools/build-course.mjs`:

```bash
node tools/build-course.mjs en a1     # исходники → native/.../en/en-a1.json
node tools/course-report.mjs          # сколько часов получилось
cd native && swift run EnglishCoachCoreTests   # валидатор содержания
cd web && npm run sync-content && npm test
```
