# Напоминания (Cloudflare Worker)

Всё приложение работает офлайном, и это его единственная сетевая часть. Причина простая:
браузер не умеет разбудить сам себя, поэтому в нужный час уведомление должен прислать
кто-то извне.

Воркер хранит **только подписки браузеров** — непрозрачный адрес и два ключа. Ни прогресса,
ни ответов, ни аккаунтов: он ничего не знает про учёбу и не может ничего о ней узнать.
Подписка удаляется сама, как только сервис пушей сообщает, что браузера больше нет.

Бесплатного тарифа Cloudflare хватает с запасом: раз в час просыпается расписание,
и на каждого подписчика уходит один HTTP-запрос.

## Развёртывание

Всё, что ниже, делается один раз. Приватный ключ в репозиторий не попадает — он живёт
в секретах воркера.

```bash
cd server

# 1. Вход в Cloudflare (откроется браузер)
npx wrangler login

# 2. Хранилище подписок. Команда напечатает id — вставь его в wrangler.toml
npx wrangler kv namespace create SUBSCRIPTIONS

# 3. Ключи и настройки
npx wrangler secret put VAPID_PRIVATE_KEY     # значение выдам отдельно, в чат
npx wrangler secret put VAPID_PUBLIC_KEY      # тот же ключ, что вшит в web/src/app/push-config.ts
npx wrangler secret put VAPID_SUBJECT         # mailto:твой@адрес
npx wrangler secret put ALLOWED_ORIGINS       # https://x8bvgp4hv8-beep.github.io
npx wrangler secret put APP_URL               # https://x8bvgp4hv8-beep.github.io/english-coach/

# 4. Публикация
npx wrangler deploy
```

Команда напечатает адрес вида `https://english-coach-reminders.<аккаунт>.workers.dev`.
Его нужно вписать в `web/src/app/push-config.ts` в `PUSH_ENDPOINT` и закоммитить —
клиент пересоберётся и выложится сам.

## Проверка

```bash
npx wrangler tail                              # живой лог
npx wrangler kv key list --binding SUBSCRIPTIONS   # кто подписан
```

Расписание срабатывает каждый час и шлёт уведомление только тем, у кого совпал **местный**
час: браузер при подписке сообщает свой сдвиг относительно UTC, поэтому родственник в
другом часовом поясе получит напоминание в своё время, а не в твоё.

## Как это выглядит у пользователя

Настройки → «Напоминание» → выбрать час → «Включить». На iPhone это работает **только**
у приложения, установленного на экран «Домой»: в обычной вкладке Safari разрешение на
уведомления не выдаётся, и экран настроек честно об этом пишет.
