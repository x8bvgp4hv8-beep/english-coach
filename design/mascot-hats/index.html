Как вставить в приложение. Скачай SVG кнопкой выше и положи в проект. React / Next: import Rhino from './rhino.svg' или вставь разметку inline — тогда CSS-классы состояний (state-wave, state-celebrate…) можно переключать из кода. React Native: react-native-svg + Reanimated для тех же трансформаций. Flutter: flutter_svg + AnimationController. Все анимации — только transform и opacity, поэтому идут на GPU и не грузят батарею.
