# Как добавить учебные материалы

Спасибо за желание расширить English Coach.

1. Создавай только оригинальные объяснения, примеры и упражнения. Не копируй базы платных платформ, учебники, иллюстрации или аудио.
2. Сохраняй `schemaVersion: 1` и уникальные стабильные идентификаторы с префиксом уровня.
3. Для `translate` указывай один `canonicalAnswer` и только действительно равнозначные `acceptedAnswers`.
4. В каждой законченной главе должны присутствовать `info`, `flashcard`, `translate`, `word_order` и `multiple_choice`.
5. Формулировки должны быть естественными, современными и соответствовать заявленному CEFR-уровню.
6. Запусти проверку перед pull request:

```bash
cd native
swift run EnglishCoachCoreTests
swift build
```

Новый пакет не принимается, если он ломает декодирование, содержит повторяющиеся ID или не проходит валидатор.
